# notita landing page

Plain static HTML/CSS/JS, no build step, no dependencies.

## Deploy with Vercel

1. [Import the repo](https://vercel.com/new) in Vercel.
2. When configuring the project, set **Root Directory** to `landing`.
3. Framework Preset: **Other** (or leave auto-detected as static). Leave the Build Command empty — there's nothing to build.
4. Deploy.

The download button always links to `github.com/Gxnza48/notita/releases/latest`, so it never needs updating when a new version ships.

## Local preview

Open `index.html` directly in a browser, or serve it:

```
npx serve landing
```
